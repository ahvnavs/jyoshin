# Getting Support for Kazeshini

Welcome to the Kazeshini support guide. We are committed to helping users inspect Linux hosts safely and cleanly.

---

## Where to Ask for Help

1. **User Documentation & Troubleshooting:**
   - First check [`docs/ERRORS.md`](file:///home/ahvnav/workspace/jyoshin/docs/ERRORS.md) for explanations of error codes (`KZ-1xxx`).
   - Check [`docs/GLOSSARY.md`](file:///home/ahvnav/workspace/jyoshin/docs/GLOSSARY.md) or run `kazeshini explain <term>` for term definitions.

2. **GitHub Discussions & Community:**
   - For usage questions, operational patterns, or configuration advice, open a thread in [GitHub Discussions](https://github.com/OWNER/kazeshini/discussions).

3. **Bug Reports:**
   - If you encounter a sensor parsing bug, crash, or unexpected behavior, run `kazeshini bugreport` to create a sanitized bundle and submit an issue using our [Bug Report Template](https://github.com/OWNER/kazeshini/issues/new?template=bug_report.md).

4. **Security Vulnerabilities:**
   - Do **NOT** post security concerns on public forums. Follow the private process outlined in [`SECURITY.md`](file:///home/ahvnav/workspace/jyoshin/SECURITY.md).
