# Project Governance

Jyōshin is committed to being an open, community-led, and neutral project suitable
for CNCF / Linux Foundation hosting.

## Principles

- **Openness**: All design discussions, roadmaps, and decisions occur publicly on GitHub.
- **Meritocracy**: Influence and maintainership are earned through consistent contributions,
  code review, and adherence to project values.
- **Predictability**: Releases follow Semantic Versioning (SemVer 2.0.0).

## Roles

### Contributors
Anyone who submits code, documentation, issues, or reviews.

### Maintainers
Maintainers are responsible for:
- Reviewing pull requests and ensuring quality and principle alignment.
- Managing releases, issue triaging, and security responses.
- Voting on architectural changes and roadmap priorities.

New maintainers are nominated by existing maintainers based on demonstrated
contributions, technical acumen, and community stewardship.
